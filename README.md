# LEGO World

### Explore o universo LEGO em um só lugar!

O **LEGO World** é um site responsivo dedicado ao universo LEGO, reunindo conteúdos sobre a história, coleções, personagens, filmes, jogos e produtos da marca.

Desenvolvido como projeto acadêmico para a disciplina **Desenvolvimento Front-End para Web**, da **Universidade Positivo**, o projeto busca aplicar na prática conhecimentos de HTML, CSS, JavaScript e Bootstrap.

---

## Sobre o projeto

A proposta do LEGO World é apresentar diferentes aspectos do universo LEGO por meio de uma experiência de navegação simples, visual e organizada.

O site reúne páginas temáticas, recursos multimídia e funcionalidades interativas, proporcionando aos visitantes uma forma de explorar o conteúdo da marca.

## Páginas do site

O projeto é composto por dez páginas:

| Página | Descrição |
|---|---|
| `index.html` | Página inicial |
| `historia.html` | História da LEGO |
| `sobre.html` | Informações sobre o universo LEGO |
| `colecoes.html` | Coleções LEGO |
| `produtos.html` | Produtos em destaque |
| `lancamentos.html` | Lançamentos |
| `personagens.html` | Personagens e minifiguras |
| `filmes.html` | Filmes, séries e conteúdo multimídia |
| `galeria.html` | Galeria de imagens |
| `contato.html` | Formulário de contato |

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** interações e funcionalidades dinâmicas.
- **Bootstrap 5:** componentes e recursos de layout.
- **Git e GitHub:** versionamento e armazenamento do código.

O Bootstrap foi instalado localmente no projeto, permitindo que seus recursos sejam utilizados mesmo sem conexão com a internet.

## Como executar o projeto

O site pode ser executado localmente, sem necessidade de instalar dependências ou configurar um servidor.

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado o ZIP.
3. Abra a pasta do projeto.
4. Execute o arquivo `index.html` em seu navegador.

Para clonar o repositório pelo terminal:

```bash
git clone https://github.com/Arthurodriguesousa/lego-world.git
```

**Observação:** mantenha a estrutura original de pastas para garantir o funcionamento correto dos caminhos dos arquivos, imagens, scripts e recursos multimídia.

## Funcionalidades e recursos

Entre os recursos implementados estão:

- Navegação entre dez páginas temáticas.
- Layout adaptável a diferentes larguras de tela.
- Componentes e estilos do Bootstrap 5.
- Interações desenvolvidas com JavaScript.
- Armazenamento de informações no navegador utilizando `localStorage`.
- Reprodução de conteúdo multimídia com áudio e vídeo.
- Formulário na página de contato.
